# 🚲 Bike Shop Manager (نظام إدارة متجر الدراجات والمبيعات)

نظام مكتبي متكامل واحترافي لإدارة محلات الدراجات ومتاجر التجزئة، مصمم بلغة Python وإطار العمل PyQt5 مع قاعدة بيانات محلية سريعة SQLite ونظام حماية وتفعيل متقدم.

---

## 🌟 المميزات الرئيسية

- **📊 لوحة التحكم (Dashboard):** مؤشرات أداء فورية، إجمالي المبيعات، الأرباح، المنتجات منخفضة المخزون، والديون المستحقة.
- **📦 إدارة المنتجات والمخزون (Inventory & Products):** إضافة وتعديل المنتجات، تتبع الكميات، أسعار الشراء والبيع، والباركود.
- **🧾 نظام الفواتير ونقاط البيع (Invoices & POS):** إنشاء فواتير البيع بسرعة، دعم الخصومات، الطباعة الفورية، وتحديد طرق الدفع (نقدي / ذمم).
- **📑 أرشيف الفواتير (Invoice History):** تصفح سجل الفواتير السابقة، الفلترة حسب التاريخ، واستعراض تفاصيل وبنود كل فاتورة.
- **💰 إدارة الديون والذمم (Debts Management):** تسجيل ديون العملاء، تسديد الدفعات جزئياً أو كلياً، وتتبع الأرصدة المتبقية بدقة.
- **⚙️ الإعدادات والنسخ الاحتياطي (Settings & Backup):** إدارة بيانات المتجر وشعاره، والنسخ الاحتياطي لقاعدة البيانات واستعادتها.
- **🔒 نظام ترخيص وأمان مدمج (Machine-Locked License):** قفل تشغيل البرنامج على الجهاز المعتمد مع أداة Keygen لتوليد مفاتيح التفعيل الموثوقة.

---

## 🛠️ التقنيات المستخدمة

- **لغة البرمجة:** [Python 3.x](https://www.python.org/)
- **واجهة المستخدم:** [PyQt5](https://riverbankcomputing.com/software/pyqt/)
- **قاعدة البيانات:** SQLite3
- **بناء ملفات التثبيت:** [Inno Setup](https://jrsoftware.org/isinfo.php) / PyInstaller

---

## 🚀 طريقة التثبيت والتشغيل

### المتطلبات الأساسية
- تثبيت Python 3.8 أو أحدث على جهازك.

### خطوات التشغيل
1. استنساخ المستودع:
   ```bash
   git clone https://github.com/alaaazayoud-debug/bike_shop_manager.git
   cd bike_shop_manager
   ```

2. إنشاء بيئة افتراضية وتفعيلها (اختياري لكن مفضل):
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```

3. تثبيت المكتبات المطلوبة:
   ```bash
   pip install PyQt5
   ```

4. تشغيل البرنامج:
   ```bash
   python main.py
   ```

---

## 🔑 تفعيل البرنامج للمطورين

لتوليد كود تفعيل لأي جهاز:
```bash
python keygen.py
```
أدخل رقم الجهاز (Machine ID) الذي يظهر في شاشة تفعيل البرنامج للحصول على كود التفعيل المخصص.
